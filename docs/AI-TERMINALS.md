# Entfernte KI-Integration

Auf ausdrücklichen Nutzerwunsch vom 26.10.2026 sind Codex, Claude Code und
Gemini/Antigravity keine Rampi-Module mehr. Dashboard, Assistent, Startadapter,
Sitzungsverwaltung und zusätzliche psmux-Installation wurden entfernt.

Bereits vorhandene Anbieterprogramme, Anmeldungen, Projekte und persönliche
Daten werden nicht gelöscht. Rampi startet oder verwaltet sie nicht.
Alte veröffentlichte Releases bleiben unverändert. Für den aktuellen Umfang
siehe [Bedienung](NATIVE-USER-GUIDE.de.md).
